UNREAL ENGINE 5 2025–2026

Making terrain cheaper to render.

Designed a cascaded terrain rendering cache to improve on runtime virtual texture caching efficiency, alongside lighting and asset pipeline improvements for mobile hardware.

UNREAL ENGINE 5 2019–2024

Ocean simulation on a mobile budget.

Implemented an ocean wave rendering approach combining Wave Particles and Fast Fourier Transform, with compute shader wave calculations running within a tight mobile GPU budget.

Compute shadersWave Particles + FFTiPad mini 6
Engineering contribution +
  • Implemented the combined Wave Particles and FFT wave rendering solution.
  • Delivered related UE5 rendering work, including staggered updates across four cascaded shadow maps for mobile distant shadows.
  • Supported Forward+ rendering with multiple dynamic point lights.

Role: Lead Programmer. The timing covers wave computation in the compute shader on iPad mini 6; it does not represent the full ocean rendering pass.
