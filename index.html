01 / TERRAIN LCC

Cascaded terrain rendering cache.

Designed terrain LCC to improve on runtime virtual texture caching efficiency for PC and mobile platforms. Introduced a Cascade Lighting Volume intermediate layer for sampling indirect lighting during rendering.

80% lower terrain rendering cost in the project workload.

The reduction refers to terrain rendering cost, rather than total frame time.

02 / TACSM SHADOWS

Texture Array Cascade Shadowmap.

Designed for PC and mobile platforms, TACSM reuses cached shadows for unchanged scenery and updates shadows for characters and other dynamic objects in real time, reducing redundant work while preserving visual quality.

Over 70% fewer shadow-rendering polygons and draw calls. Saved 2–3 ms of GPU time on Samsung Galaxy S25.

03 / ASSET OPTIMIZATION

Building batching and tree LOD tools.

Applied texture arrays to support automatic batching of building models. Planned tree LODs and built an automatic generation tool using density-based billboard cards and impostors.

Asset and toolchain improvements for PC and mobile platforms.

Project captures across platforms.
